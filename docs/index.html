Features

Everything you need to learn faster

A complete toolkit for Coursera power users. All features run locally in your browser.

▶
Lecture Video Automation
Smooth auto-play, speed controls, and automatic progression across all course video lectures with zero manual clicks.
📚
Reading & Discussion Assistants
Auto-scroll and completion markers for reading assignments and discussion forums.
📝
Practice Question Helpers
Sequential navigation through ungraded practice modules. Strictly for practice, not graded assessments.
💾
Course Backup Engine
Download video lectures, subtitles, and attachments as ZIPs. Up to 10 parallel workers for speed.
🔊
Audio & Speech Guidance
Optional Web Speech API announcements for hands-free learning milestones.
🌙
Modern Dark UI
Midnight Navy base with purple & cyan accents, WCAG 2.1 AA focus indicators, and inline search.

Get Started

Install in 5 steps

Works on Chrome, Brave, Edge, or any Chromium browser supporting Manifest V3.

1
Clone or DownloadRun git clone https://github.com/NodeNexus/Coursera-Automator-Pro.git or download ZIP.
2
Open Browser ExtensionsNavigate to chrome://extensions in your Chromium browser.
3
Enable Developer ModeToggle Developer mode in the upper-right corner.
4
Load Unpacked ExtensionClick Load unpacked and select the folder containing manifest.json and the dist/ folder.
5
You’re Ready!The Coursera Automator Pro icon appears in your toolbar. Press Alt+B to open the dashboard.
